# Visor Muestra Apurímac – Supervisión ALP

Visor móvil preparado a partir de `Muestra_Apurimac.xlsx`.

## Muestra
- Total: 25 SED
- Principal: 20
- Alternativa: 5
- Prioridad alta: 8
- Prioridad normal: 17

## Capas
- Esri WorldStreetMap
- Esri Satélite
- Esri Híbrido

## Marcadores
- Rojo: muestra PRINCIPAL
- Azul: muestra ALTERNATIVA

## Interacción
Al tocar un marcador se muestra información resumida:
- SED
- Sistema eléctrico
- Tipo de muestra
- Prioridad
- Desviación
- Criterio de selección
- Consumo teórico P1
- Promedio de consumo medido

El único botón fijo es `Ruta sugerida`, pensado para uso desde celular.
